# FootyArena

A hub for the best football games with friends

## 🎮 Games

- **Football Imposter** - Online multiplayer guessing game (inspired by Insider)

## 🚀 Tech Stack

### Frontend
- **React** with Vite
- **React Router** for navigation
- **Socket.IO Client** for real-time multiplayer
- **Deployed on**: [Vercel](https://vercel.com)

### Backend
- **Node.js** with Express
- **Socket.IO** for WebSocket connections
- **Deployed on**: [Render](https://render.com)
- **Uptime**: Cron-Job.org pings every 10 minutes to keep server alive

## 🛠️ Local Development

### Frontend
```bash
npm install
npm run dev
```
Runs on `http://localhost:5173`

### Backend
```bash
cd backend/football-imposter
npm install
npm start
```
Runs on `http://localhost:3000`
